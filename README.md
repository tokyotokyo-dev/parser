## Структура проекта

```
yt_parser/
├── main.py                   # Главный файл, требующий запуска
├── settings.json             # Конфигурация
├── games.txt                 # Список игр (по одной на строку)
├── requirements.txt
└── modules/
    ├── channel_collector.py  # Этап 1: YouTube Search API
    ├── channel_filter.py     # Этап 2: Гео + статистика
    ├── email_extractor.py    # Этап 3: Playwright(библиотека питона) /about(место где отображается почта у канала)
    └── excel_exporter.py     # Этап 5: Экспорт .xlsx
```

## Установка

```bash(powershell)
pip install -r requirements.txt
playwright install chromium <- требуется для парсинга
```

## Настройка settings.json

| Параметр                  | Описание                                        |
|---------------------------|-------------------------------------------------|
| `youtube_api_key`         | Ключ Google Cloud → YouTube Data API v3         |
| `whitelist_countries`     | Разрешённые страны                              |
| `blacklist_countries`     | Заблокированные страны                          |
| `min_subscribers`         | Минимум подписчиков                             |
| `min_videos`              | Минимум видео на канале                         |
| `max_days_since_upload`   | Максимум дней с последнего ролика               |
| `regions_to_search`       | Регионы для поиска (regionCode)                 |


## Запуск через консоль, если требуется:

```bash
python main.py
```

!!!! 
Парсер поддерживает **чекпоинты** — если прервать (Ctrl+C),
при следующем запуске продолжит с того же места.



## Выходной файл results.xlsx

| Название канала | Ссылка | Email | Подписчики | Страна | Видео | Последний пост |
|-----------------|--------|-------|------------|--------|-------|----------------|

Строки с найденным email подсвечены зелёным.


!!! Если после нескольких парсингов выборка очень сильно упала - поменять/добавить в games.txt новые ключевые слова или в channel collector.py добавить разные формулировки запросов в:
queries = [
    f"{game} новая формулировка,
]
В ином случае после парсинга большого кол-ва каналов выборка будет давать довольно мало результатов и запросы будут улетать практически просто так(это можно использовать и как смену направления поиска вместо games.txt)
